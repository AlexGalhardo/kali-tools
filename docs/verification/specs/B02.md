# B02 macOS routes and Wi-Fi evidence

- Date: 2026-10-23. Host: Linux, Go 1.27.3.
- Status: the routing-counter parser and the CoreWLAN/Keychain state mapping are tested. Apple Silicon has not run them. Parent B02 stays open. No release tag was created.

## What was verified

`parseDarwinCounters` reads one `RTM_IFINFO2` fixture, keeps the first row for a repeated interface index, skips a short or non-matching message, and rejects a truncated or oversized dump. Default-route selection and the live sysctl call are compiled for darwin. This host did not execute them.

`networkFromCoreWLAN` accepts a network name, keeps a channel, drops a dBm reading from the percent field, and returns `location_consent_required` for an empty name. `secretFromKeychain` returns the key only for status 0, `no_saved_key` for a missing item, `permission_required` when a prompt would be required, and `unsupported` for a missing entitlement or an unknown status. The value is not copied into those errors. The cgo call disables `LAContext` interaction, so it does not prompt.
