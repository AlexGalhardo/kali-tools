## Step 2: pure netlink and procfs parsers

Parser and fuzz-seed tests first failed on absent parse functions. The untagged parser validates netlink headers, bodies, attributes, alignment and address lengths before slicing, rejects kernel errors, maps state precedence and link-local zones, drops NOARP rows, and caps raw rows at 65,536. The procfs parser bounds the complete read to 1 MiB plus one sentinel byte, skips malformed rows, preserves complete/permanent/incomplete distinctions and treats zero MACs as unknown. Neither parser transmits packets.

Synthetic tests cover 4 MiB and +1 dump bytes, 1 MiB and +1 procfs bytes, 65,536/65,537 raw rows, 32/33-byte MACs, malformed/truncated headers/attributes/padding and all state mappings. Review caught unknown-family rows bypassing attribute validation; parsing now validates their attribute framing before skipping them. Caller-owned bytes do not escape into output slices.

Verification: 30-second fuzz smoke passes with 791,337 executions and no crasher. Platform/network race tests and full Go tests/vet pass. Platform coverage rises from 81.4% to 93.1%; netlink helpers are 100%, procfs parser 93.9%, exceeding the pure-file 90% gate. scripts/task.mjs includes the named 30-second fuzzer; node syntax check passes. Windows native shim, Linux glue and all public neighbor interfaces remain for later numbered steps. AC-5/6/7 and DA-2 now have automated evidence; Docker and native checks are not run.

Step 2 is committed/pushed as [0821f30](https://github.com/AlexGalhardo/kali-tools/commit/0821f30). ## Steps 3–4: OS adapters

Windows layout/conversion tests first failed on absent shim structs, conversion and Host.Neighbors. The adapter now calls the fixed system GetIpNetTable2 procedure, bounds the entry count, checks context before/after OS work, converts owned summaries and always frees a successful table. Struct size is 88 bytes; all seven offsets and the table offset of 8 pass on Windows amd64. Synthetic conversion is 100% covered, including IPv6 link-local zones, states/router flag and MAC lengths 0/32/33.

The read-only host smoke passes on Windows build 26200 with 114 normalized rows in the recorded run. It does not ping, open sockets or compare a gateway with Get-NetNeighbor; AC-8/9 and DA-7/8 stay open. This is partial host-call evidence only. The allocation/free contract follows [Microsoft GetIpNetTable2](https://learn.microsoft.com/en-us/windows/win32/api/netioapi/nf-netioapi-getipnettable2).

Linux glue reads RTM_GETNEIGH and falls back to bounded /proc/net/arp only after a netlink call failure, never after a parse failure. The fallback for other OSes returns unsupported; its tagged unit test is present but not executed on Windows. Linux/macOS cross-vet and Windows arm64 vet pass; these do not qualify native behavior. The Linux kernel dump is bounded after syscall.NetlinkRIB returns, as specified; that syscall itself is not interruptible. Docker/Linux runtime acceptance remains unavailable on this host.

Platform race tests pass. Final Windows platform coverage is 90.7%, above the 81.4% baseline; pure netlink helpers remain 100%, procfs 93.9%, Windows row conversion 100%, native Neighbors 76.5%. The remaining native error branches are not simulated as hardware acceptance.

Steps 3–4 are committed/pushed as [27809b9](https://github.com/AlexGalhardo/kali-tools/commit/27809b9). Full Go tests/vet, cross-vet and frontend typecheck/build pass.
