# C01 complete CLI evidence

- Date: 2026-10-21, Windows build 26300, Go 1.27.3.
- Status: in progress; numbered implementation steps are committed separately. This record does not claim C01 complete.
- Baseline: CLI coverage 96.3%, cmd/kali-tools 69.2%; 19 frontend workflows after A08.

## Step 1: exit codes

`TestExitCodeTable` first failed to compile because `cli.ExitCode` did not exist. The exported constants and mapping now cover success, all domain codes and unknown codes. The existing safe contract envelope is retained. The two old cancellation/provider exit assertions were updated to the explicitly specified exit statuses; their result/error/redaction assertions remain unchanged.

Verification: `go test ./...` passes, `go test -race -count=1 ./internal/adapter/cli ./cmd/kali-tools` passes. Coverage: CLI 96.5%, cmd 69.2%, both at least baseline. Formatting and lint run before commit. AC-4 mapping is implemented; per-command error injection and remaining AC/DA/gates are pending later steps. The default remains JSON during steps 1–5 as specified.

Native SSH AC-16/DA-11 not run. CLI human output, command table, full help, jobs/history/settings commands, reveal confirmation, progress, documentation freeze, migration and Docker updates remain pending.

## Step 2: per-command parsing

Introduced the table for the existing commands, root and leaf global flags, `NeedsApp`, duration parsing with overflow-safe bounds, help with exit 0, JSON pre-scan, and non-echoing flag errors. The legacy execution body is temporarily retained behind the validated invocation while the following steps add commands; default output remains JSON. A new per-command regression first failed because `version --port 1` had been silently accepted. It now exits 2. Root/command help and unknown flags need no application. Tests cover timeouts 100/600000ms and 99/600001ms, duration spellings, overflow and secret flag values. Initial legacy invocation fixtures retain old valid/invalid forms.

The H07 CLI driver now explicitly requests JSON and uses the shared exit mapping. This was necessary immediately: timeout 99 now fails during parsing, where output mode must already be explicit. The unchanged acceptance scenarios pass. Full suite passes; CLI coverage at this intermediate step is 89.6% and cmd remains 69.2%; final coverage gate is assessed after all steps. An initial Windows temporary-directory cleanup failure in a Wails acceptance case did not repeat on the isolated or full rerun.

## Step 3: read-only commands

Added capabilities, tools, the honest unsupported neighbors stub, Wi-Fi show, jobs list/show, history list and settings get. Job IDs require exactly 32 lowercase hex characters; show checks the live snapshot then retained history. List filters terminal jobs unless --all is present. New fake-backed fixtures use the existing H07 providers, fixed UTC time and a seeded history ID. No application method or platform test seam was added. New JSON command tests failed on unknown-command/positional errors before implementation, then pass; help, ID boundary and list-filter assertions pass. CLI history clearing arrives in step 4, so the acceptance skip is retained until then.
