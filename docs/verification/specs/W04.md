# W04 secure web server verification

Date: 2026-10-22. Status: implemented, automated baseline verified; full boundary and native acceptance remain open. This is an owner-authorized unsigned development checkpoint.

## Controls and evidence

The production chain is recovery, redacted access log, headers, Host allowlist, CrossOriginProtection, Fetch Metadata, bounded in-flight requests, session and routes. Every API route except session exchange requires valid cookie/bearer authentication, including SSE; the regression test reads registered patterns from routes.go. Tokens are 32 random bytes encoded as 43 URL-safe characters. Launch and session values differ; cookie names include the actual bound port and cookies are host-only, HttpOnly, SameSite Strict and Secure under TLS. Both comparisons use crypto/subtle. URL fragments are scrubbed by the browser.
