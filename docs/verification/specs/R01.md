# R01 contract freeze

Date: 2026-10-23. Status: the supported surface is frozen in the documents below. Hardware acceptance is not frozen and is not accepted.

## Frozen surface

- CLI commands, flags, exit codes and JSON shapes: [CLI contract](../../cli.md). Contract fixtures live under `internal/adapter/cli/testdata/contract`.
- HTTP routes, session rules, body limits and error statuses: [HTTP contract](../../http.md). `TestHTTPContractMatchesRoutes` fails when a route, error status or body limit drifts.
- Schema version 1 for the CLI envelope, neighbor and discovery CSV, and the SQLite database.
- Settings: `language` is `en` or `pt-BR`; `retention_days` is 1 through 365. A new database defaults to `en` and 30 days.
- Operating systems: [packaging](../../packaging.md). Windows x64, Ubuntu 24.04 x64 and macOS arm64. Anything else is not supported.

## Agreement

The README, `doctor` and the CLI contract use the same Ubuntu 24.04 baseline sentence: Debian 13 and Kali are best-effort and come with no guarantee. `doctor` prints that sentence on every OS. It is the Linux baseline, not a claim that the current machine is Ubuntu. The doctor `capture` and `wifi` strings describe the Windows path. Live capability rows are the per-OS states. The README does not list every Kali tool. Nmap is not run.

The HTTP contract no longer says Linux and macOS Wi-Fi and live capture stay `unsupported` until a provider exists. Those providers exist. `unsupported` means this build has no provider. `permission_required` means the provider exists and this process was denied.

## Not claimed

Native install, a clean machine, or any hardware checkbox. R02 and R03 stay open. No release tag was created.
