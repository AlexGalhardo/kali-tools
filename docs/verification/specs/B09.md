# B09 DNS inspection evidence

- Date: 2026-10-23. Host: Linux, Go 1.27.3, Node.js 24.21.0.
- Status: comparison, SOA/NS, DNSSEC, DoH/DoT, adapters and the Diagnostics panel are implemented. Docker AC-10 passed in GitHub run 39970855209 (`tests/integration` ok). No release tag was created. B09 has no native hardware gate.
- B10 moved the plain lab DNS listener from UDP 5353 to UDP 5300 so the fixture can bind mDNS on 5353. The comparison fixture still answers `fixture.test` A `192.0.2.42` on that new port.

## What was verified

`Inspect` compares the system resolver with explicit resolvers, checks SOA and NS consistency, validates a DNSSEC chain from DS anchors, and checks DoH and DoT. Network failures stay on the result. `Inspect` returns an error only for `invalid_input`, `cancelled` or the 30-second deadline.

The built-in root anchors were checked on 2026-10-23 against <https://data.iana.org/root-anchors/root-anchors.xml>. Key tags 20326 and 38696 match the spec digests. Retired tag 19036 (validUntil 2019-01-11) is present in that file and is not used.

The lab zone `signed.test` uses the fixed ED25519 seeds. Its DS is pinned as `signed.test. IN DS 38590 15 2 b3d09e28ce56fd36df2da483c42ee8de3987d26747f553a6f15baa5a760485e4`. `TestPinnedSignedDS` verifies that text and both RRSIGs.

UDP port 5300 answers `fixture.test` A `192.0.2.42` and NXDOMAIN for other names, including `missing.test`. B10 moved it off 5353. `differs.test` A `192.0.2.42` was added so the two-resolver comparison has two successful answers. Glue A records are that fixture's non-loopback IPv4. The internal compose network has no route to `192.0.2.1`, and dialing it used to fall back to `127.0.0.1`, so authoritative queries hit the test container. `NewForLab` maps name-server names to ports because the fixture has one address. Production `Inspect` does not set that hook. `TestSOANSConsistency` binds both authoritative servers on `127.0.0.1` with distinct ports, because macOS `lo0` has no `127.0.0.2`.

`github.com/miekg/dns` v1.1.73 (BSD-3-Clause) is imported by `internal/dnsinspect/wire.go`, `dnssec.go`, `anchors.go` and `cmd/lab-fixture` only.
