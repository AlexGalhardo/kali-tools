# B03 privilege boundary evidence

- Date: 2026-10-23. Host: Linux, Go 1.27.3.
- Status: [ADR 011](../../adr/011-no-privileged-helper.md) records the owner decision. There is no privileged helper and no helper IPC. Native acceptance was not run. No release tag was created.

## What was verified

`bpfAccessCapability` reports `permission_required` and names `access_bpf` when BPF devices exist and cannot be opened. It reports `unsupported` when a device can be opened, and when none exist. The text does not tell the user to `chmod` a device. `bpf_darwin.go` contains no permission-changing call. On this Linux host, `capture_live` stays `unsupported` and names `sudo setcap cap_net_raw+eip`.

Npcap's missing-install state still includes https://npcap.com/#download and says the free license forbids redistribution. The Administrators-only state says to start an elevated terminal.

## Commands

`go test -count=1 -timeout 60s ./internal/capture/ -run 'TestBPF|TestLinuxCaptureNamesSetcap'` and `go test -count=1 -timeout 60s ./internal/adapter/pcap/ -run TestNpcapStatusMapping` passed.
