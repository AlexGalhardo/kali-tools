# B07 packaging matrix

Date: 2026-10-23. Status: the archive matrix, notices, uninstall and writable-data path are documented. Clean-machine WebView checks were not run.

## What changed

[Packaging](../../packaging.md) names the three archives CI already builds: Windows x64, Ubuntu 24.04 x64 and macOS arm64. It states that there is no installer. Uninstall is deleting the unpacked directory. `history.db` stays in `os.UserConfigDir()/kali-tools/history.db`, with the legacy `hacker-tools/history.db` fallback. `scripts/package.mjs` already copies `THIRD_PARTY_NOTICES.txt` and `dependencies.json` and refuses a non-arm64 macOS package. `scripts/release.mjs` already requires `windows-x64.zip`, `linux-x64.tar.gz` and `macos-arm64.zip` before writing `SHA256SUMS`.

`docs/development.md` no longer says native CI supplies both Mac architectures.

## Checks

`node scripts/markdown.mjs` was run with this change. `node scripts/package.mjs` was not run here: this environment has no GTK or WebKitGTK, and packaging needs a native desktop build. The published `v0.7.0-dev.1` assets are the last archives this repository produced. This document does not rebuild them.

## Not claimed

A clean machine, a missing WebView2 runtime, a missing WebKitGTK library, Intel macOS, Windows ARM, Debian 13 or Kali as a supported baseline. The B07 parent stays open. Runbook step 15 records the hardware check and does not close the parent by itself.
