## What was verified

`internal/network/http.go` reports `httptrace` phases, the ten allowlisted security headers, and the redirect target. `CheckRedirect` still returns `http.ErrUseLastResponse`. An explicit `redirects` value of 1..5 issues one new request per hop and stops on a loop, an invalid target, the hop limit, or the diagnostic deadline. Cookies and other non-allowlisted headers are not copied into the result. The CLI flag is `--redirects`. The diagnostics page shows the phases, the header table, and the redirect target as text, not a link.
