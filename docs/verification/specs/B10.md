- Date: 2026-10-23. Host: Linux, Go 1.27.3, Node.js 24.21.0.
- Status: mDNS, SSDP, SNMP, adapters and the Discovery panels are implemented. Docker AC-9 is the private-lab job on this pull request. AC-11 and AC-12 are native and were not run. No release tag was created.

## What was verified

`Discover` validates an up, non-loopback interface and an IPv4 prefix of /24 or narrower that overlaps that interface. mDNS and SSDP drop out-of-scope answers, cap responders at 256, and never request an SSDP `LOCATION`. `QuerySNMP` requires `Owned=true`, reads the system MIB, and caps interface rows at 256. A wrong community times out. A v3 wrong digest is `unauthorized`. Error text and history summaries do not contain `synthetic-community` or `synthetic-pass`.

`github.com/hashicorp/mdns` v1.0.7 is MIT. `github.com/gosnmp/gosnmp` v1.46.0 is BSD-2-Clause, with Go BSD-3-Clause ASN.1 notices, so the SPDX expression is `BSD-2-Clause AND BSD-3-Clause`. Both are permissive. `golang.org/x/net` stays at v0.60.0 because that mdns tag does not require v0.61.0.

The lab fixture moved plain DNS from UDP 5353 to UDP 5300, answers SSDP `uuid:kali-tools-lab::upnp:rootdevice`, serves mDNS `fixture._kali-lab._tcp.local.`, and answers SNMP `sysName` `kali-tools-lab` on UDP 1161.

GitHub run [39975981864](https://github.com/AlexGalhardo/kali-tools/actions/runs/39975981864) failed AC-9 and the Windows and macOS race jobs. `hashicorp/mdns` QueryContext binds `224.0.0.251:5353` with a nil interface and returns `setsockopt: no such device` inside the lab, which was reported as `mdns_bind_failed` before SSDP. A failed library query is now repeated from an ephemeral socket with the unicast-response bit. The loopback unit test uses the host's IPv4 loopback name, because `lo` exists on Linux and not on Windows or macOS. AC-9 remains the lab job.
