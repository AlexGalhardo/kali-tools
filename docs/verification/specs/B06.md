# B06 diagnostic bundle

Automated checks for the redacted diagnostic zip. SQLite backup/export fixtures, compatibility fixtures for other export formats, and the rest of B06 are not claimed here.

## What ran

| Check | Result |
| --- | --- |
| `go test ./internal/bundle/ ./internal/app/ ./internal/adapter/cli/ ./internal/adapter/httpapi/ ./internal/adapter/wailsui/` | The secret fixtures `synthetic-psk-do-not-leak`, `snmp-community-secret`, `PAYLOAD-BYTES-SECRET` and `secret-192.0.2.55-key` are absent from the zip bytes and the unzipped text. The same IPv4 address stays `ip1`. A labelled SSID, a dotted hostname and a MAC do not survive. RFC3339 timestamps stay. |
| CLI `doctor --bundle` | Writes mode `0600` and JSON `data.path` / `data.format=zip`. A directory path exits 2 and the error does not include the path. |
| `GET /api/doctor/bundle` | `application/zip`, `Cache-Control: no-store`, fixed filename. The Wi-Fi reveal value `synthetic-test-key` is absent. |
| Wails `SaveDiagnosticBundle` | Writes the zip from the save dialog. Cancelling the dialog returns false and no error. |
| Bundle construction | Does not call `Current` or `Reveal`. History text is redacted. Capture packets are not a field of the report. |
