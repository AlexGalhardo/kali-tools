## Contract gap requiring a scope decision

The first real Windows `ProberContract` run failed:

```text
=== RUN   TestProberContract/rejects_invalid_target
    prober.go:12: unexpected provider state: lookup a;whoami: no such host
--- FAIL: TestProberContract/rejects_invalid_target
```

`probe.ICMP.Run` delegates directly to the native function, which calls DNS without `network.ValidateHost`. H07 requires `invalid_input` or `unsupported` for this target, while its non-goals allow only storage constant exports in production and explicitly require stopping and reporting other production gaps. The proposed correction is to validate the host in the shared `probe.ICMP.Run` adapter before delegating. Authorization was requested asynchronously; elapsed time is not treated as approval. The regression remains pending rather than being weakened, skipped or pushed as a failing main-branch test.

The independent suites, fakes and acceptance drivers can be saved as numbered H07 steps while that decision is pending. H07's parent PLAN checkbox remains unchecked.

## Deviations and follow-ups

- H03's real port names are retained: `ToolRunner.RunNmap` rather than the illustrative `InspectServices`, `Prober.Provider/Run`, and live capture's result/artifact/error triple.
- Specifications accept a scenario factory rather than a single driver value. This resolves the illustrative signature's conflict with the requirement to build a fresh application and driver for every scenario, including timeout/count boundary cases.
- `Host.InventoryFunc` and `LiveCapture.CaptureFunc` move the existing metrics/cancellation test hooks into shared fakes, preserving context instrumentation. Their configured result fields remain the normal suite path. No production interface changed.
- Test-local aliases retain existing test vocabulary while every ordinary fake implementation now lives in `internal/porttest/fake`; specialized recording spies still observe context propagation.
- `TestRequireHonestState` uses package `porttest` to test the pure private helper, as the spec's prose requires; it does not fake `testing.T`.
- No HTTP driver was added. W01 owns HTTP; C01 owns CLI history and deletion of the explicit skip.
- The pending ICMP correction is the only discovered failing real contract on this host. It is not silently accepted as an honest state.
