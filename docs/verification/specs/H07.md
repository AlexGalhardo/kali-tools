## Contract gap requiring a scope decision

The first real Windows `ProberContract` run failed:

```text
=== RUN   TestProberContract/rejects_invalid_target
    prober.go:12: unexpected provider state: lookup a;whoami: no such host
--- FAIL: TestProberContract/rejects_invalid_target
```

`probe.ICMP.Run` delegates directly to the native function, which calls DNS without `network.ValidateHost`. H07 requires `invalid_input` or `unsupported` for this target, while its non-goals allow only storage constant exports in production and explicitly require stopping and reporting other production gaps. The proposed correction is to validate the host in the shared `probe.ICMP.Run` adapter before delegating. Authorization was requested asynchronously; elapsed time is not treated as approval. The regression remains pending rather than being weakened, skipped or pushed as a failing main-branch test.

The independent suites, fakes and acceptance drivers can be saved as numbered H07 steps while that decision is pending. H07's parent PLAN checkbox remains unchecked.
