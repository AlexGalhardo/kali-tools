# B01 Linux adapters evidence

- Date: 2026-10-23. Host: Linux, Go 1.27.3.
- Status: the Ubuntu 24.04 LTS baseline is recorded. Route and counter inventory reads netlink and falls back to procfs. Neighbors already used netlink. nl80211 metadata and NetworkManager `GetSecrets` are implemented. libpcap capture is implemented for a Linux build tagged `pcap`; an untagged build reports `unsupported`. Native acceptance was not run. No release tag was created.

## What was verified

[ADR 010](../../adr/010-linux-baseline.md) names Ubuntu 24.04 LTS as the documented baseline, matching the CI `ubuntu-24.04` runner. Debian 13 and Kali are best-effort and come with no guarantee. `doctor` JSON field `baseline` and the human doctor line say that sentence. The README says the same.

`parseNetlinkRoutes` keeps a default route and drops a more specific one. An IPv6 default gateway is formatted. `parseNetlinkLinks` reads `IFLA_STATS64` byte counters and the interface name. Truncated and oversized dumps are rejected. The procfs parsers still read an IPv4 default route and `/proc/net/dev` counters. `Inventory` on this host returns adapters without error.

`signalPercent` maps nl80211 mBm onto 0–100 and keeps an explicit percent when the radio provides one. `secretFromNM` returns the PSK, `enterprise`, `open_network`, or `no_saved_key`. A NetworkManager error that contains `synthetic-psk` is rewritten without that text. `Current` on this host returns either a connected network or an explicit `no_connection`, `unsupported`, `permission_required`, or `failed` error. That is not a hardware acceptance run.

`libpcapError` maps `permission denied` and `operation not permitted` to `permission_required` and names `CAP_NET_RAW`. The message does not echo the underlying text and does not say to use `sudo`. Any other open error is `failed` with a fixed sentence. On this untagged host, `Status` is `unsupported` and says this build does not include libpcap. The `linux && pcap` capture loop is not executed here. That is not a hardware acceptance run.
