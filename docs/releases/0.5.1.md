# kali-tools 0.5.1

**Status:** Unsigned development preview. Hardware qualification remains open.

## Summary

Patch release with CI and test isolation fixes. Continued implementation of W01 (web server) and C01 (CLI).

### What's new

- HTTP capability-test assertions now match translated labels for unsupported capabilities on platforms where Wi-Fi/capture are unavailable.
- Serve tests are now independent of compiled frontend assets and isolated configuration paths on every platform, fixing clean-checkout quality checks and the non-root Docker laboratory.

### Downloads

Archives for Windows x64, Ubuntu 24.04 x64, macOS Intel and macOS Apple Silicon include the desktop application, CLI, license, notices and build metadata. Verify downloads against `SHA256SUMS`. No trusted signing identity; read release notes before testing.
