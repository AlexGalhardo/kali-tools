# kali-tools 0.6.0-dev.2

**Status:** unsigned development preview; hardware qualification remains open. Not a release-qualified build.

## Changes

- Adds TLS audit to Diagnostics in Wails and browser modes, authenticated `POST /api/tls/audit` and `kali-tools tls-audit --target <host>`.
- Reports the presented certificate chain, explicit trust verification, negotiated protocol/cipher/ALPN, OCSP stapling, SCT counts and TLS 1.0–1.3 support.
- Adds pinned zlint v3.7.2 certificate findings, bounded reports, deterministic ordering and 100-row pagination. History stores counts only.
- Keeps client limitations separate from server rejection. Untrusted/expired certificates are findings; no exploit checks or application data are sent.

## Verification and limitations

See [B08 evidence](../verification/specs/B08.md), [checkpoint verification](../verification/0.6.0-dev.2.md) and the [changelog](../../CHANGELOG.md). Automated tests use controlled local TLS endpoints. Both browser transports are covered, including accessibility and narrow-screen rendering.

This release includes Windows x64 CLI/desktop binaries and source. It does not include Linux/macOS native binaries. All development artifacts are unsigned; BUILD.json discloses signed:false and the source commit. Platform trust-store acceptance, native Wails IPC for the new operation, hardware qualification and signing/notarization remain open. The optional research-grade zcrypto legacy TLS client is not implemented; zcrypto is used only by zlint for certificate parsing. B09–B11 remain for subsequent work.
