# Hacker Tools

Desktop network diagnostics and security toolkit planned with Go, Wails, React, TypeScript, Base UI and Tailwind CSS v4.

Current stage: research and first brainstorming completed; detailed delivery plan prepared. No application implementation or release exists yet.

- [Research](docs/tools-research.md)
- [Brainstorming](docs/brainstorming.md)
- [Delivery plan](PLAN.md)

Windows 11 leads the alpha, including Wi-Fi password display and live capture. Linux/macOS validation follows. Prefer native Go implementations and optional Nmap/TShark adapters for remaining gaps. SQLite history, PT-BR/English UI and a noncommercial project are confirmed decisions.

CI/CD source and Docker test setup are prepared during the structure phase; workflows must remain inactive.
